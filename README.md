# Online Employee Selection & Hiring System

A recruitment platform that automates the hiring process from job posting to interview scheduling. Built as my capstone project and awarded distinction-level feedback.

![Screenshot](screenshot.png)

## Features
- **Job posting:** admins create and publish vacancies
- **Online applications:** candidates apply through the website
- **Automated scoring:** a rule-based engine scores each candidate, reducing manual review time for every hiring round
- **Admin shortlisting:** admins review scores and shortlist candidates
- **Interview scheduling:** shortlisted candidates are booked for interviews
